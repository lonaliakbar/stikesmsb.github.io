Masuk ke panel admin

Gunakan token GitHub yang punya izin menulis ke repositori situs.

Cara membuat token
  1. Buka GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Pilih Generate new token, lalu pada Repository access pilih Only select repositories dan centang repo situs ini.
  3. Pada Permissions → Repository permissions, set Contents ke Read and write.
  4. Salin token dan tempel di atas. Token hanya disimpan di tab ini dan dikirim langsung ke api.github.com.
